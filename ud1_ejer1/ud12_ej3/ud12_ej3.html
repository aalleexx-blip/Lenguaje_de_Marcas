VS Code

VS Code es una IDE ligera y potente desarrollada por Microsoft para escribir y editar código fuente.

Funciona en multiples plataformas como las principales: Windows, macOS y Linux, además de contar con una versión para la nube.

Cuenta con una enorme comunidad de desarrollo y es de uso libre.

VS Studio Code fue anunciada inicialmente el 29 de abril de 2015 por Microsoft y su primera versión estable en abril de 2016, la versión 1.0.

Trucos

Si tu código está desordenado, mal alineado o copiaste un fragmento que rompió toda la estética visual, este comando lo ordenara: Shift + Alt + F

Para iniciar el editor directamnete desde la consola, ejecuta el comando code.
