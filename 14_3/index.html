1. Etiquetas

Las etiquetas son la base estructural de cualquier documento HTML. Permiten definir si un bloque de texto es un párrafo, un título principal o un elemento de una lista.

Normalmente se utilizan en pares, contando con una etiqueta de apertura y otra de cierre, aunque existen excepciones conocidas como etiquetas vacías.

2. Atributos

Los atributos proporcionan información adicional sobre los elementos HTML y siempre se especifican en la etiqueta de apertura.

Están formados por un nombre y un valor, normalmente separados por el signo igual y con el valor entre comillas, como por ejemplo en las clases o identificadores.

3. Enlaces

Los enlaces se crean utilizando la etiqueta ancla y son el componente que convierte a la web en una verdadera red interconectada de documentos.

El atributo más importante de esta etiqueta es href, el cual indica la dirección de destino a la que el navegador debe redirigir al usuario al hacer clic.

4. Imágenes

Para añadir imágenes en una página web se utiliza una etiqueta específica que no requiere cierre, pero que sí exige indicar la ruta del archivo visual.

Es obligatorio incluir siempre un texto alternativo mediante el atributo alt, lo que garantiza la accesibilidad para lectores de pantalla y casos donde la imagen no cargue.
